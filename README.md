# Justin Kinney Lab Website Test

## Local preview

If a local server is not already running, start one from the repository root:

```sh
python3 -m http.server 8000
```

Then open <http://localhost:8000/>. You can check whether port 8000 is already in use with `lsof -nP -iTCP:8000 -sTCP:LISTEN`.

- `team.html` - Team members page
